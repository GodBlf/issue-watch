# 08: 移除仓库时联动取消全部追踪

**Status:** ready-for-agent



**What to build:** 后台移除监控仓库时提前展示影响范围，并在移除生效时结束该仓库全部追踪，取消相应未发送动态。

**Blocked by:** 03：按独立间隔广播新评论并可靠投递

- [ ] 移除确认展示该仓库会取消的当前追踪数量，清晰区分新建 Issue 通知与追踪动态的处理。
- [ ] 仓库移除实际被接受时取消该仓库全部当前追踪和未发送追踪投递；配置提交被拒绝或冲突时，不提前取消追踪。
- [ ] 防止确认与提交之间新增追踪遗漏清理；移除完成后后台列表与实际检查状态一致。
- [ ] 保留现有新建 Issue 待投递通知，继续按原规则发送；其他仓库追踪和投递不受影响。
- [ ] 重新添加仓库不会自动恢复之前的 Issue 追踪；新建 Issue 监控继续遵守既有恢复进度规则。
- [ ] 验证后台完整流程、配置失败、并发新增/检查/发送、服务重启以及两类通知的不同取消行为。
