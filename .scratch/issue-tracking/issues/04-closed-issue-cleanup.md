# 04: 关闭事件通知后自动清理追踪

**Status:** ready-for-agent



**What to build:** Issue 关闭时发送最后一批动态及关闭通知，并自动从当前追踪清单清理，停止后续检查。

**Blocked by:** 03：按独立间隔广播新评论并可靠投递

- [ ] 追踪开始后的任何关闭原因均结束追踪，包括已解决及未计划处理；历史关闭事件不结束新一轮追踪。
- [ ] 查到关闭事件即结束，即使同一个检查间隔内已经重新打开；通知说明关闭与当前状态。
- [ ] 最后一批动态及关闭通知合并处理；结束后后台当前列表移除，后续不再检查该次追踪。
- [ ] 保留必要事件及投递记录供最终通知重试；重启、部分发送失败不会恢复追踪或向已成功接收者重复发送。
- [ ] 重新打开不自动恢复；显式重新添加开放 Issue 建立新起点，不受上一轮关闭记录和旧任务影响。
- [ ] 查询失败不得触发清理；与人工取消并发时遵守人工取消不再发送未发消息的规则。
- [ ] 验证关闭、关闭后重开、故障期间关闭、历史关闭、最终投递重试及人工取消竞争场景。

依据已确认的 Issue 追踪设计生成；用户已确认票据粒度和依赖，正式发布。尚未开始实现。
