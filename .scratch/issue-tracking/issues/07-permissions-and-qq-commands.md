# 07: 后台授权并启用 QQ 追踪命令

**Status:** ready-for-agent



**What to build:** 后台按用户分别配置添加、取消权限，QQ 用户通过 URL 命令管理同一份共享清单，允许符合规则的用户查询。

**Blocked by:** 02：后台添加、查询和取消共享 Issue 追踪

- [ ] 所有 QQ 用户默认没有追踪修改权限，不设 QQ 管理员角色；权限列表按 user_openid 录入、搜索、分页和编辑，也支持未订阅用户。
- [ ] 添加、取消权限分别勾选且显式保存，保存后立即反馈，不额外确认；权限持久化并在每次命令执行时读取有效授权。
- [ ] `/track <Issue URL>` 和 `/untrack <Issue URL>` 只接受完整 Issue URL；与后台复用相同校验、重复处理及追踪起点规则。
- [ ] 无对应权限回复“权限不足：你没有执行此命令的权限，请联系后台管理人员。”；不存在回复“该 Issue 不存在”，未追踪取消回复“该 Issue 未在追踪中”。
- [ ] `/tracking` 查询共享清单，`/tracking <仓库 URL>` 按仓库查询；订阅者或拥有任一修改权限者可查询，其余用户无权限。列表过长分段或提供明确的查询分页方式。
- [ ] 取消权限允许取消任意共享追踪，回复明确指出影响共享清单；修改权限不要求先订阅。
- [ ] 退出广播不删除权限；撤销权限不取消既有追踪；`/bind`、`/unbind` 原行为保持。
- [ ] 验证完整后台授权到 QQ 执行流程、两项权限组合、撤销即时生效、未订阅授权用户、查询资格及权限与订阅独立性。
