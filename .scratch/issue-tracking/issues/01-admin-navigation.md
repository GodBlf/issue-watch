# 01: 后台拆分导航并保留现有管理流程

**Status:** ready-for-agent



**What to build:** 将现有后台重组为可独立进入的概览、仓库、广播接收者、用户权限、设置视图，为新增追踪功能提供清晰入口，同时使现有管理功能保持可用。

**Blocked by:** None (can start immediately)

- [ ] 桌面采用侧栏、手机采用紧凑导航；只显示当前视图，刷新和浏览器前进后退保持正确位置。尚未实现的新功能入口明确显示待接入状态。
- [ ] 现有健康状态、异常摘要和投递队列归入概览；仓库、订阅及设置原有读写流程仍可完整操作。
- [ ] 现有仓库和接收者列表提供搜索及分页，空列表和无匹配结果有明确提示。
- [ ] 添加及编辑采用独立表单或侧边面板，显式保存；刷新保留未保存输入，离开未保存表单时提醒。
- [ ] 错误出现在相关字段或操作附近；提交期间防重复点击；移除订阅和仓库保留确认及现有业务说明。
- [ ] 浏览器验证桌面、窄屏、导航恢复、草稿保留及现有管理流程；原有管理接口和同源写入校验不被削弱。
