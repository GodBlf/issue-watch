# 06: 广播明确关联 PR 的状态变化

**Status:** ready-for-agent
Implementation: complete



**What to build:** 明确关联到被追踪 Issue 的 PR 合并、关闭或重新打开时，广播状态摘要；Issue 结束追踪后停止跟进。

**Blocked by:** 05：广播跨仓库引用及明确关联 PR；04：关闭事件通知后自动清理追踪

- [x] 跟进 GitHub 明确关联的 PR，通知合并、未合并关闭和重新打开；仅引用的 PR 不继续跟进。
- [x] 历史已关联 PR 可以作为当前追踪的状态跟进对象，但不补发追踪起点前的状态变化。
- [x] 合并导致关闭不产生两条内容重复的通知；同轮多项动态合并进对应 Issue 摘要。
- [x] 服务故障恢复后补查可读取的状态事件，支持分页及去重，不仅比较最终状态而遗漏中间的关闭或重开。
- [x] Issue 因关闭或人工取消结束追踪后，不再发起该次追踪的关联 PR 跟进；自动关闭保留最后通知重试，人工取消取消未发送通知。
- [x] 验证明确关联与仅引用的区别、合并、关闭、重开、故障期间多次变化及 Issue 结束时的并发边界。
