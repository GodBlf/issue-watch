# 02: 广播订阅移除与备注维护

Status: ready-for-agent
Implementation: complete
Blocked by: 01 — 广播订阅查看与添加

**What to build:** 管理员在广播订阅列表中补填、修改、清空 QQ 号备注，并在确认后移除订阅；管理操作与机器人退出保持一致，不增加订阅封禁。

- [x] 已有订阅以及通过 /bind 加入的订阅均可补填、修改和清空备注；备注选填、不要求唯一，不影响投递身份。
- [x] 备注修改持久化，刷新页面和重启后保留；修改不存在或已移除的订阅明确报错，不意外创建订阅。
- [x] 移除前请求确认并说明取消未发送通知、正在发出的请求仍可能送达，以及对方可以重新 /bind。
- [x] 移除取消该订阅未发送和待重试的投递并删除备注，不影响其他接收者的订阅或投递。
- [x] 移除与投递并发时沿用现有退订语义，不宣称可以撤回已经开始发送的请求。
- [x] 手动或通过 /bind 重新加入均创建新订阅身份，不恢复旧积压或已删除备注；管理页面与 /unbind 在备注生命周期上保持一致。
- [x] 重复移除及操作期间机器人 /unbind 的情况得到明确反馈，不误操作之后重新加入的新订阅身份。
- [x] 所有新增写操作复用请求来源防护，失败时保留健康展示，并刷新接收者列表与相关状态。
- [x] 验证备注编辑/清空及持久化、移除取消投递、其他接收者不受影响、重新加入、机器人交互及浏览器确认/取消流程。
