## Standards

独立规范审查未发现需要修改的问题。领域术语遵循词汇表；广播订阅加入、退出和重新加入遵循 ADR 0001；部署保留 ADR 0002 的人工恢复政策。

## Spec

独立规格审查发现两项 P2 缺陷，均已修复并通过针对性回归验证：

- 启动期间独立读取配置可能使管理接口与监控循环使用不同数据库，并将尚未采用的配置报告为已应用。现在管理服务使用主程序已加载的启动配置和数据库；回归测试模拟文件在启动期间变更。
- 请求期间仍可编辑输入，保存完成会覆盖较新的输入。现在提交期间锁定对应表单输入与按钮，并暂停接收者列表的自动重绘；浏览器边界测试覆盖添加接收者、备注与轮询间隔的进行中状态。

自行复核还补充了 Linux 配置替换时保留属主、属组和权限，避免 root 容器保存后改变管理员的文件访问方式。配置拒绝状态同步源版本；仓库列表未变时保留原控件，避免周期刷新打断键盘操作。

## 部署说明

已有本地 Compose 需将配置迁移到配置目录；生产服务器需由管理员重新安装可写目录挂载的 Compose。宿主机端口仍为回环地址。页面保存重新格式化 TOML，不保留原注释；非协作外部编辑器在最后文件检查与原子替换间的竞争不能被版本检查完全消除，避免同时编辑同一文件。
