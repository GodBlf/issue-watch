# 01: 管理员登录与一年会话

**What to build:** 管理员通过 SSH 安全设置初始密码，再从浏览器登录现有管理界面。全部管理页面和管理 API 统一验证身份，会话固定有效一年且跨重启保留。本工单先交付完整登录链路；公网开放由后续工单完成。

**Blocked by:** None (can start immediately).

Status: ready-for-agent
Implementation: complete

- [x] 提供可通过 SSH 调用的初始密码设置入口，不提供默认密码、注册、第三方登录或邮箱找回；秘密输入不进入命令行参数、shell 历史、日志或版本库。
- [x] 未初始化、认证配置非法或认证存储不可读取时拒绝管理访问，不退回匿名管理。只持久化带盐的现代密码哈希，不保存明文密码。
- [x] 登录页支持提交密码、正确和错误反馈及成功后进入现有管理界面；错误反馈不泄露凭据或内部异常。公开例外仅限登录及必要静态资源，不夹带管理数据。
- [x] 统一保护全部管理页面与读取、写入 API，包括配置、通知目标、QQ 号备注、仓库订阅、监控仓库、共享 Issue 追踪及追踪命令权限；仅伪造固定管理请求头不能访问。
- [x] 每次成功登录创建独立、密码学安全随机的会话；服务端持久化验证摘要和生命周期信息，不接受客户端指定会话凭据，不存储可直接使用的原始会话值。
- [x] 会话从登录成功起固定有效 365 天，访问不续期，服务更新或重启后仍有效；允许多个设备分别建立独立会话。服务端判断有效期，客户端无法延长。
- [x] 登录 Cookie 使用 Secure、HttpOnly、SameSite=Strict、根路径和一致的持久化到期时间，不设置跨域共享；不在 localStorage 中保存会话，不在浏览器中保存密码。
- [x] 未认证管理 API 返回 401；管理页面引导登录。浏览器清除 Cookie 或会话过期后可重新登录，界面不承诺浏览器一定保存整整一年。
- [x] 为后续公网入口提供清晰的认证边界：内部回环健康检查可以继续运行，不能因此豁免管理数据和写操作；公网健康信息不得匿名暴露。内部例外不能仅依赖 Host 或转发头。
- [x] 保留现有跨站写入保护，不为打通登录而开放任意来源；后续工单负责完整公网 HTTPS Origin 适配及登录限流。完成此工单不代表具备公网开放条件。
- [x] 沿用真实管理 HTTP 集成测试和临时持久化存储，验证初始化、登录、无效凭据、全部管理入口身份保护、Cookie 属性、一年到期边界、访问不续期及重启保留；通过可控时间验证期限，不等待真实一年。
- [x] 现有管理业务测试显式登录，监控仓库、通知目标、仓库订阅、Issue 追踪及命令权限的既有行为保持正常，不通过全局关闭认证维持测试通过。
- [x] 更新本地初始化和登录使用说明，说明纯 HTTP 测试只能验证 Secure Cookie 的响应契约，实际浏览器行为由后续 HTTPS 验收确认。
