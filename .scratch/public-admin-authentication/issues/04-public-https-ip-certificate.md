# 04: 公网 HTTPS 入口与 IP 证书自动续期

**What to build:** 提供可安装和验收的公网 HTTPS 部署流程，让管理员直接使用服务器 IP 登录管理。可信 IP 证书自动续期，应用端口保持回环隔离，证书和认证故障均可通过 SSH 恢复。

**Blocked by:** 02 — 退出登录与 SSH 密码恢复；03 — 公网登录防护与 HTTPS 同源校验。

Status: ready-for-agent

- [ ] 使用宿主机 Nginx 提供 HTTPS 代理，默认访问地址为 `https://172.197.176.142/`，不要求域名或额外子路径。部署配置统一指定 IP、外部 Origin 和证书目标。
- [ ] 公网 TCP 443 提供管理入口；代理转发到既有宿主机回环 8081，容器端口发布仍仅绑定回环。不能通过公网直接访问 8081 绕过代理。
- [ ] 公网 TCP 80 仅提供 ACME HTTP-01 挑战路径，其他路径拒绝；登录页、管理页面及 API 不通过 HTTP 提供。证书或认证故障不允许降级为明文或匿名管理。
- [ ] 代理覆盖客户端提供的身份相关转发头，并与应用可信代理配置匹配；外部伪造 Host 或转发头不能获得内部健康检查豁免或绕过限流。
- [ ] 保留既有宿主机回环健康检查和部署验收能力。公网健康状态入口要求有效登录或由代理明确拒绝，内部例外不扩展到管理数据或管理写操作。
- [ ] 使用 Certbot 5.4 或以上版本、webroot 验证和 shortlived profile 签发可信 IP 证书；先在 ACME 测试环境验证，再申请生产证书，不让普通测试反复请求生产签发。
- [ ] 配置无人值守续期与续期后重载，适配 IP 证书 160 小时有效期；重载前验证配置及证书，失败保留可用配置且留下可检查的结果，不以人工反复申请替代自动续期。
- [ ] 安装或部署前检查现有代理、80/443 端口占用、工具版本、系统支持、宿主机防火墙及云网络可达性；冲突或验证失败时报告具体原因，不覆盖未知服务，不以关闭鉴权规避。
- [ ] 公网接入前必须完成密码初始化与登录恢复、防暴力尝试、跨站保护和可信代理配置；部署不能把未完成防护的中间版本提前开放。
- [ ] 对可控 HTTPS 环境进行浏览器验收：浏览器信任证书，安全 Cookie 实际保存与携带，脚本不能读取 Cookie，登录、管理、退出和重新登录正常；明确纯 HTTP fixture 不能替代此验证。
- [ ] 外部验收验证 443 可用、80 仅允许挑战路径、8081 不可达、管理页面和全部管理 API 不可匿名访问、公网健康信息不可匿名读取；内部回环健康检查继续正常。
- [ ] 验收跨站退出和管理写入被拒绝、代理后来源限流有效、多设备退出隔离，以及 SSH 重置后已打开页面立即失去管理权限；覆盖 02 和 03 的完整集成结果。
- [ ] 使用 ACME 测试环境或 dry-run 验证自动续期、挑战文件访问和重载流程；覆盖续期失败可观察、配置或证书错误不能替换正常配置、失败不开放 HTTP 管理。
- [ ] 更新完整安装、初始密码设置、登录使用、续期检查、证书故障、密码恢复及紧急全量撤销说明。新版本启动验收失败时停止并报告，不自动恢复旧数据库，遵守既有人工恢复策略。
- [ ] 交付部署配置、自动化和可复现验收结果；本工单文字不表示线上条件已经核实。实际线上执行应在实施会话已授权的范围内进行，无法验证的外部条件须如实记录，不宣称已上线。
