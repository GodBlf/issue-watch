## Agent skills

### Issue tracker

Track this project's issues and specs as local Markdown files under `.scratch/`. Before creating, fetching, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before triaging issues or changing their status, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase or proposing domain changes, read `docs/agents/domain.md`.
